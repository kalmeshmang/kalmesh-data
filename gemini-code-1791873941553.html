GitHub ಸಂಪೂರ್ಣ ಕನ್ನಡ ನೋಟ್ಸ್

ಜಾವಾ (Java) ಪ್ರಾಜೆಕ್ಟ್ ಉದಾಹರಣೆಯೊಂದಿಗೆ ಹಂತ-ಹಂತವಾದ ಮಾರ್ಗದರ್ಶಿ

1. Git ಮತ್ತು GitHub ಎಂದರೇನು?

Git ಎನ್ನುವುದು ನಿಮ್ಮ ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲಿ ಕೋಡ್ ಬದಲಾವಣೆಗಳನ್ನು ಟ್ರ್ಯಾಕ್ ಮಾಡಲು ಬಳಸುವ Version Control System ಆಗಿದೆ. GitHub ಎನ್ನುವುದು ಆ ಕೋಡ್ ಅನ್ನು ಆನ್‌ಲೈನ್‌ನಲ್ಲಿ (Cloud ನಲ್ಲಿ) ಸುರಕ್ಷಿತವಾಗಿ ಶೇಖರಿಸಿಡಲು ಮತ್ತು ಇತರರೊಂದಿಗೆ ಹಂಚಿಕೊಳ್ಳಲು ಬಳಸುವ ವೆಬ್ ತಾಣವಾಗಿದೆ.

ಉದಾಹರಣೆ: ನಿಮ್ಮ ಮೊಬೈಲ್‌ನಲ್ಲಿ ಫೋಟೋಗಳನ್ನು Google Drive ಅಥವಾ iCloud ನಲ್ಲಿ ಬ್ಯಾಕಪ್ ಮಾಡಿದಂತೆ, ನಿಮ್ಮ ಜಾವಾ ಪ್ರಾಜೆಕ್ಟ್ ಕೋಡ್ ಅನ್ನು GitHub ನಲ್ಲಿ ಬ್ಯಾಕಪ್ ಮಾಡಲಾಗುತ್ತದೆ.

2. ಜಾವಾ ಪ್ರಾಜೆಕ್ಟ್ ಉದಾಹರಣೆಯೊಂದಿಗೆ GitHub ವರ್ಕ್‌ಫ್ಲೋ

ನೀವು ಒಂದು ಜಾವಾ ಪ್ರಾಜೆಕ್ಟ್ Calculator.java ಸಿದ್ಧಪಡಿಸಿದ್ದೀರಿ ಎಂದಟ್ಟುಕೊಳ್ಳಿ. ಅದನ್ನು GitHub ಗೆ ಹೇಗೆ ಕಳುಹಿಸುವುದು?

ಪ್ರಮುಖ ಹಂತಗಳು ಮತ್ತು ಕಮಾಂಡ್‌ಗಳು:

  • git init: ನಿಮ್ಮ ಪ್ರಾಜೆಕ್ಟ್ ಫೋಲ್ಡರ್‌ನಲ್ಲಿ Git ಅನ್ನು ಆಕ್ಟಿವೇಟ್ ಮಾಡಲು. 
    git init
  • git add: ಹೊಸ ಜಾವಾ ಫೈಲ್‌ಗಳನ್ನು ಟ್ರ್ಯಾಕಿಂಗ್‌ಗೆ ಸೇರಿಸಲು. 
    git add Calculator.java
  • git commit: ಬದಲಾವಣೆಗಳನ್ನು ಅಧಿಕೃತವಾಗಿ ಸೇವ್ ಮಾಡಲು (ಒಂದು ಮೆಸೇಜ್‌ನೊಂದಿಗೆ). 
    git commit -m "Added Calculator java file"
  • git branch: ಮುಖ್ಯ ಬ್ರ್ಯಾಂಚ್‌ಗೆ ಹೆಸರು ನೀಡಲು (ಸಾಮಾನ್ಯವಾಗಿ main). 
    git branch -M main
  • git remote add origin: ನಿಮ್ಮ ಲೋಕಲ್ ಕೋಡ್ ಅನ್ನು GitHub ಆನ್‌ಲೈನ್ ಲಿಂಕ್‌ಗೆ ಜೋಡಿಸಲು. 
    git remote add origin https://github.com/your-username/java-project.git
  • git push: ಕೋಡ್ ಅನ್ನು ಆನ್‌ಲೈನ್ GitHub ಗೆ ಅಪ್‌ಲೋಡ್ ಮಾಡಲು. 
    git push -u origin main

3. ಬ್ರಾಂಚಿಂಗ್ (Branching) ಮತ್ತು ಕೊಲಾಬರೇಷನ್

ಒಂದೇ ಪ್ರಾಜೆಕ್ಟ್‌ನಲ್ಲಿ ಅನೇಕ ಡೆವಲಪರ್‌ಗಳು ಕೆಲಸ ಮಾಡುವಾಗ Branch ಬಳಸುವುದು ಬಹಳ ಮುಖ್ಯ. ಮುಖ್ಯ ಕೋಡ್ ಹಾಳಾಗದಂತೆ ಹೊಸ ಫೀಚರ್‌ಗಳನ್ನು ಪ್ರತ್ಯೇಕ ಬ್ರ್ಯಾಂಚ್‌ನಲ್ಲಿ ಬರೆಯಬಹುದು.

# ಹೊಸ ಬ್ರ್ಯಾಂಚ್ ರಚಿಸಲು ಮತ್ತು ಅದಕ್ಕೆ ಹೋಗಲು
git checkout -b feature-login

# ಬದಲಾವಣೆಗಳನ್ನು ಮಾಡಿ ಪುಷ್ ಮಾಡಲು
git push origin feature-login

Pull Request (PR) ಎಂದರೇನು?

ನೀವು ಮಾಡಿದ ಹೊಸ ಜಾವಾ ಕೋಡ್ ಬದಲಾವಣೆಗಳನ್ನು ಮೇನ್‌ ಬ್ರ್ಯಾಂಚ್‌ಗೆ ಸೇರಿಸುವಂತೆ ಪ್ರಾಜೆಕ್ಟ್ ಲೀಡರ್‌ಗೆ ವಿನಂತಿ ಮಾಡುವುದನ್ನು Pull Request ಎನ್ನಲಾಗುತ್ತದೆ. ಅವರು ಕೋಡ್ ಪರಿಶೀಲಿಸಿ (Review) ಅಪ್ರೂವ್ ಮಾಡುತ್ತಾರೆ.

4. ದಿನನಿತ್ಯ ಬಳಸುವ ಇತರ ಪ್ರಮುಖ ಕಮಾಂಡ್‌ಗಳು

  • git status - ಪ್ರಸ್ತುತ ಫೈಲ್‌ಗಳ ಸ್ಥಿತಿ ತಿಳಿಯಲು.
  • git pull - ಆನ್‌ಲೈನ್‌ನಲ್ಲಿರುವ ಇತ್ತೀಚಿನ ಕೋಡ್ ಅನ್ನು ನಿಮ್ಮ ಕಂಪ್ಯೂಟರ್‌ಗೆ ಡೌನ್‌ಲೋಡ್ ಮಾಡಿಕೊಳ್ಳಲು.
  • git clone [URL] - GitHub ನಲ್ಲಿರುವ ಬೇರೆಯವರ ಪ್ರಾಜೆಕ್ಟ್ ಅನ್ನು ನಿಮ್ಮ ಕಂಪ್ಯೂಟರ್‌ಗೆ ಕಾಪಿ ಮಾಡಿಕೊಳ್ಳಲು.
