DevOps ಮೂಲ ಪರಿಚಯ

HTTPD, Tomcat ಮತ್ತು Jenkins - ಸರಳ ಚಿತ್ರಗಳು ಮತ್ತು ಅನಿಮೇಷನ್ ವಿವರಣೆ

1. HTTPD (Apache Web Server) ಎಂದರೇನು?

HTTPD (Apache HyperText Transfer Protocol Daemon) ಎನ್ನುವುದು ಒಂದು ವೆಬ್ ಸರ್ವರ್ ಆಗಿದೆ. ಬಳಕೆದಾರರು ಬ್ರೌಸರ್‌ನಲ್ಲಿ (Chrome, Safari) ವೆಬ್‌ಸೈಟ್ ಓಪನ್ ಮಾಡಿದಾಗ HTML, CSS ಮತ್ತು ಚಿತ್ರಗಳನ್ನು (Static Content) ಬಳಕೆದಾರರಿಗೆ ತಲುಪಿಸುವ ಕೆಲಸವನ್ನು ಇದು ಮಾಡುತ್ತದೆ.

ಉದಾಹರಣೆ: ಇದು ಒಂದು ಹೋಟೆಲ್‌ನಲ್ಲಿರುವ "ಸ್ವಾಗತಕಾರರ (Receptionist)" ಇದ್ದಂತೆ. ಗ್ರಾಹಕರು ಕೇಳಿದ ತಕ್ಷಣ ಮೆನು ಕಾರ್ಡ್ ಅಥವಾ ಸರಳ ವಸ್ತುಗಳನ್ನು ತಂದುಕೊಡುತ್ತಾರೆ.

2. Apache Tomcat ಎಂದರೇನು?

Tomcat ಎನ್ನುವುದು ಒಂದು Java Servlet Container ಆಗಿದೆ. ಇದು ಕೇವಲ ಸ್ಟಾಟಿಕ್ ಪೇಜ್‌ಗಳನ್ನು ಮಾತ್ರವಲ್ಲದೆ, Java ಆಧಾರಿತ ಡೈನಾಮಿಕ್ ಅಪ್ಲಿಕೇಶನ್‌ಗಳನ್ನು (JSP, Servlets) ರನ್ ಮಾಡಲು ಸಹಾಯ ಮಾಡುತ್ತದೆ. ಬ್ಯಾಕ್‌ಎಂಡ್ ಲಾಜಿಕ್ ಅನ್ನು ಪ್ರೊಸೆಸ್ ಮಾಡಲು ಇದು ಮುಖ್ಯ.

ಉದಾಹರಣೆ: ಇದು ಹೋಟೆಲ್ ಅಡುಗೆಮನೆಯ ಇದ್ದಂತೆ. ಗ್ರಾಹಕರು ಆರ್ಡರ್ ಮಾಡಿದ ವಿಶೇಷ ತಿನಿಸುಗಳನ್ನು (Dynamic food) ಅಡುಗೆಮನೆಯಲ್ಲಿ ತಯಾರಿಸಿ ಕಳುಹಿಸಲಾಗುತ್ತದೆ.

3. Jenkins (CI/CD Tool) ಎಂದರೇನು?

Jenkins ಎನ್ನುವುದು ಆಟೋಮೇಷನ್ (Automation) ಟೂಲ್ ಆಗಿದೆ. ಸಾಫ್ಟ್‌ವೇರ್ ಡೆವಲಪರ್‌ಗಳು ಕೋಡ್ ಬರೆದ ತಕ್ಷಣ, ಅದನ್ನು ಆಟೋಮ್ಯಾಟಿಕ್ ಆಗಿ ಟೆಸ್ಟ್ ಮಾಡಿ, ಬಿಲ್ಡ್ ಮಾಡಿ, ಪ್ರೊಡಕ್ಷನ್‌ಗೆ ತಲುಪಿಸಲು (CI/CD Pipeline) ಜೆಂಕಿನ್ಸ್ ಸಹಾಯ ಮಾಡುತ್ತದೆ. ಕೈಯಿಂದ ಮಾಡುವ ಕೆಲಸವನ್ನು ಇದು ಯಂತ್ರದ ಮೂಲಕ ಸುಲಭಗೊಳಿಸುತ್ತದೆ.

ಉದಾಹರಣೆ: ಇದು ಒಂದು ಆಟೋಮ್ಯಾಟಿಕ್ ಫ್ಯಾಕ್ಟರಿ ಕನ್ವೇಯರ್ ಬೆಲ್ಟ್ ಇದ್ದಂತೆ. ಡೆವಲಪರ್ ಕಚ್ಚಾ ಸಾಮಗ್ರಿ (Code) ಹಾಕಿದರೆ ಸಾಕು, ಅದು ತಾನಾಗಿಯೇ ಪರಿಶೀಲಿಸಿ ಸಿದ್ಧ ಉತ್ಪನ್ನವನ್ನು (App) ಹೊರತರುತ್ತದೆ.
