🚀 GitHub ಸಂಪೂರ್ಣ ನೋಟ್ಸ್

ಸುಲಭವಾಗಿ GitHub ಕಲಿಯಲು ಇದು ನಿಮ್ಮ ಮಾಡರ್ನ್ ಮಾರ್ಗದರ್ಶಿ.

1. Git ಮತ್ತು GitHub ಎಂದರೇನು?

Git: ಇದು ಒಂದು Version Control System. ನಿಮ್ಮ ಕೋಡ್‌ನಲ್ಲಿ ಮಾಡುವ ಬದಲಾವಣೆಗಳನ್ನು ಟ್ರ್ಯಾಕ್ ಮಾಡಲು ಮತ್ತು ಹಳೆಯ ವರ್ಷನ್‌ಗೆ ಮರಳಲು ಇದು ಸಹಾಯ ಮಾಡುತ್ತದೆ.

GitHub: ಇದು Git ಪ್ರೊಜೆಕ್ಟ್‌ಗಳನ್ನು ಆನ್‌ಲೈನ್‌ನಲ್ಲಿ (Cloud ನಲ್ಲಿ) ಸೇವ್ ಮಾಡಿಡಲು ಮತ್ತು ಪ್ರಪಂಚದ ಎಲ್ಲಿಂದಲಾದರೂ ಬೇರೆ ಡೆವಲಪರ್‌ಗಳ ಜೊತೆ ಕೆಲಸ ಮಾಡಲು ಬಳಸುವ ವೆಬ್‌ಸೈಟ್.

ಚಿತ್ರ: ಕೋಡಿಂಗ್ ಮತ್ತು ಆನ್‌ಲೈನ್ ಕೊಲಾಬೊರೇಷನ್ ಪರಿಕಲ್ಪನೆ

2. ಮೂಲ ಪರಿಕಲ್ಪನೆಗಳು (Basic Concepts)

  • Repository (Repo): ಇದು ನಿಮ್ಮ ಪ್ರೊಜೆಕ್ಟ್ ಫೈಲ್ಸ್ ಮತ್ತು ಅದರ ಹಿಸ್ಟರಿ ಸೇವ್ ಆಗುವ ಜಾಗ (Folder).
  • Commit: ನೀವು ಮಾಡಿದ ಬದಲಾವಣೆಗಳನ್ನು ಸೇವ್ ಮಾಡುವ ಪ್ರಕ್ರಿಯೆ (ಫೋಟೋ ತೆಗೆದಿಟ್ಟಂತೆ).
  • Push: ಲೋಕಲ್ ಕಂಪ್ಯೂಟರ್‌ನಿಂದ ಕೋಡ್ ಅನ್ನು GitHub ಆನ್‌ಲೈನ್ ಪ್ರೊಜೆಕ್ಟ್‌ಗೆ ಕಳುಹಿಸುವುದು.
  • Pull: ಆನ್‌ಲೈನ್‌ನಿಂದ ಇತ್ತೀಚಿನ ಕೋಡ್ ಅನ್ನು ನಿಮ್ಮ ಕಂಪ್ಯೂಟರ್‌ಗೆ ಡೌನ್‌ಲೋಡ್ ಮಾಡಿಕೊಳ್ಳುವುದು.

3. ಪ್ರಮುಖ Git ಕಮಾಂಡ್‌ಗಳು (Commands)

ಪ್ರೊಜೆಕ್ಟ್ ಶುರು ಮಾಡಲು ಬಳಸುವ ಪ್ರಮುಖ ಕಮಾಂಡ್‌ಗಳು:

git init                 # ಹೊಸ Git ರೆಪೊಸಿಟರಿ ಆರಂಭಿಸಲು
git status               # ಫೈಲ್ಸ್‌ಗಳ ಸ್ಥಿತಿ ತಿಳಿಯಲು
git add .                # ಬದಲಾದ ಫೈಲ್ಸ್‌ಗಳನ್ನು ಸ್ಟೇಜ್ ಮಾಡಲು
git commit -m "message"  # ಬದಲಾವಣೆಗಳನ್ನು ಸೇವ್ ಮಾಡಲು
git push origin main     # GitHub ಗೆ ಕೋಡ್ ಕಳುಹಿಸಲು

4. Branching ಮತ್ತು Merging ಎಂದರೇನು?

ಮುಖ್ಯ ಕೋಡ್‌ಗೆ (Main Branch) ತೊಂದರೆ ಕೊಡದೆ, ಹೊಸ ಫೀಚರ್ ಟೆಸ್ಟ್ ಮಾಡಲು Branch ಬಳಸಲಾಗುತ್ತದೆ.

git checkout -b feature-branch   # ಹೊಸ ಬ್ರಾಂಚ್ ಮಾಡಿ ಅದಕ್ಕೆ ಹೋಗಲು
git merge feature-branch         # ಹೊಸ ಬ್ರಾಂಚ್ ಅನ್ನು ಮೇನ್ ಬ್ರಾಂಚ್ ಜೊತೆ ಸೇರಿಸಲು

5. GitHub ನ ಪ್ರಯೋಜನಗಳು

  • ಸುರಕ್ಷಿತವಾಗಿ ಕೋಡ್ ಆನ್‌ಲೈನ್‌ನಲ್ಲಿ ಇರುತ್ತದೆ.
  • ಟೀಮ್ ಜೊತೆ ಒಟ್ಟಿಗೆ ಕೆಲಸ ಮಾಡಬಹುದು.
  • ಕೋಡ್‌ನಲ್ಲಿ ಯಾರಾದರೂ ತಪ್ಪು ಮಾಡಿದರೆ ಹಳೆಯ ಒಳ್ಳೆಯ ವರ್ಷನ್‌ಗೆ ಸುಲಭವಾಗಿ ಹೋಗಬಹುದು.
